# Agent Spec

## Overview
A lightweight conversational assistant built with ADK Python and `agents-cli` for local testing. It provides time checking and basic calculation tools.

## Language
`python`

## Example Use Cases
- "What time is it in UTC?" -> Agent calls `get_current_time` and reports current timestamp.
- "Calculate 15% tip on a bill of $84.50" -> Agent calculates the tip using `calculate` and returns breakdown.

## Tools Required
- `get_current_time`: Returns current formatted timestamp and timezone.
- `calculate`: Safely computes basic mathematical operations using Python arithmetic.

## Constraints & Safety Rules
- Answer clearly and concisely.
- Use tools whenever calculations or current time information is requested.

## Success Criteria
- Successfully scaffolded with `agents-cli scaffold create simple-agent --agent adk --prototype`.
- Successfully responds to queries using `agents-cli run`.
