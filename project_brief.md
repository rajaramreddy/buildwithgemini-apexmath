# My agent: ApexMath (Pre-Calc & AP Calculus Tutor)
One-liner: A conversational agent that helps high school students master Pre-Calculus and AP Calculus concepts to score high on AP exams, with a catalog of curriculum units, targeted problem banks, and diagnostic review materials.

Tool coverage:
- Memory: Student topic mastery levels (e.g. Limits, Derivatives, Integrals, Series), error logs/common pitfalls, study streaks, and past practice exam scores across sessions.
- Tools: Fetch practice problems by topic and difficulty, submit student answers and log attempt results, retrieve targeted concept review summaries, and generate custom diagnostic quizzes.
- Catalog/UI: Curriculum unit cards, practice problem cards (with hidden hints/solutions), and student progress scorecard tables rendered with A2UI.
- Image gen: Diagrammatic visuals for geometric and graphical concepts (e.g., solids of revolution, Riemann sum approximations, tangent lines, unit circle trigonometry).
- Sandbox: Python code sandbox with SymPy for symbolic math execution (computing derivatives, integrals, limits, checking algebraic equivalences) and calculating mastery score percentages.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for symbolic calculus verification (SymPy), Cloud Trace for session performance observability
